# 零基础 15 个月学日语

从五十音开始，用 15 个月把日语基础打扎实的个人学习仓库。所有计划、笔记、错题和进度都记录在这里，用于自我跟踪和复盘。

**目标**：15 个月后达到 JLPT N4 水平 —— 能读懂简单日文段落，能应对旅行、购物、问路等日常场景的基础会话。

## 快速开始

不需要安装任何环境，全部是 Markdown 笔记，用任意编辑器打开即可；也可以直接在 GitHub 网页上阅读。

```bash
# 拉到本地
 git clone https://github.com/ewliejar-glitch/ewliejar_1st.git
 cd ewliejar_1st
```

之后按这个顺序上手：

1. 先看下面的「15 个月路线」，确认自己处在第几个阶段
2. 打开 `progress/` 里日期最新的周记录，从上次停下的地方继续
3. 每次学习结束，在当周记录的「今日内容」里补一行，第二天不用回想上次学到哪

如果只想浏览、不参与维护，直接在网页上点开对应文件就行，无需克隆。

## 15 个月路线

| 阶段 | 月份 | 重点内容 | 阶段验收 |
| --- | --- | --- | --- |
| 一、入门 | 1–2 | 五十音（平假名/片假名）、声调、基本发音规则 | 看到假名能立刻读出，听写正确率 90% 以上 |
| 二、N5 基础 | 3–6 | 基础语法（判断句、存在句、动词三类）、约 800 词、日常寒暄 | 能做自我介绍、描述日常作息 |
| 三、N5 巩固 | 7–9 | N5 语法收尾、助词辨析、短文阅读、听力精听 | 完成 N5 真题，正确率 70% 以上 |
| 四、N4 进阶 | 10–13 | N4 语法与句型、约 1500 词、长句拆解、基础写作 | 能读 300 字短文，写 100 字左右短文 |
| 五、冲刺与复盘 | 14–15 | 真题训练、错题重做、口语输出练习 | 达到 N4 及格线水平，能完成 3 分钟日常对话 |

> 说明：以上是个人节奏安排，不是官方课程。进度落后时不往后堆，先回头补当阶段的验收项。

## 目录结构

当前只有本文件，其余目录按下面的规划逐个建立：

```text
.
├── README.md        本文件：目标、路线、快速开始
├── progress/        每周学习记录（按 YYYY-MM-DD 命名）
├── notes/           语法、词汇、发音等专题笔记
├── mistakes/        错题与易混淆点汇总
└── resources.md     在用教材、App、网站清单
```

## 学习约定

- 每天至少 30 分钟，宁可短而连续，不搞周末突击
- 新语法当天造 3 个自己的句子，不用教材例句
- 错题当天记进 `mistakes/`，周末统一重做一遍
- 每月最后一周只复习不学新内容
