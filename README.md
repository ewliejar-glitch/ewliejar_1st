# 零基础 15 个月学日语

从五十音开始，用 15 个月把日语基础打扎实的个人学习仓库。所有计划、笔记、错题和进度都记录在这里，用于自我跟踪和复盘。

**目标**：15 个月后达到 JLPT N4 水平 —— 能读懂简单日文段落，能应对旅行、购物、问路等日常场景的基础会话。

## 快速开始

不需要安装任何环境，全部是 Markdown 笔记，用任意编辑器打开即可；也可以直接在 GitHub 网页上阅读。

```bash
git clone https://github.com/ewliejar-glitch/ewliejar_1st.git
cd ewliejar_1st
```

之后按这个顺序上手：

1. 打开 `plans/month-01.md`，这是前两个月的逐周逐日安排（2026-11-09 开始）
2. 把 `notes/kana-chart.md` 当查字典用：每个假名都标了拼音和英文近似读法
3. 每次学完在当周记录里补一行，第二天不用回想上次学到哪

只想浏览、不参与维护的话，直接在网页上点开对应文件就行，无需克隆。

## 发音怎么学（不用听写）

仓库里**没有听写练习**。没有语音材料的情况下，靠「音标 ↔ 假名」双向翻译来学：

- **看音标写假名**：给 `xi → し`、`ci → つ`、`qia → ちゃ`，写出对应假名
- **看假名写音标**：反向自查，比正向更能暴露漏洞
- **发音锚点**：每个假名都用拼音或英文近似标注，如 し = 拼音「西」、ち = 拼音「七」、つ = 拼音「次」、ら = 拼音「拉」

两个必须记住的前提：

1. 拼音和英文只是**近似**，不是日语原音，不要因为它像某个中文字就带上去声调
2. 日语只有「每拍等长」和「高 / 低」两种调。初期先不管调，只把每拍读得一样长

全量对照表在 `notes/kana-chart.md`，包含平假名、片假名、浊音、拗音和长音 / 促音 / 拨音规则。

## 15 个月路线

| 阶段 | 月份 | 重点内容 | 阶段验收 |
| --- | --- | --- | --- |
| 一、入门 | 1–2 | 五十音（平假名 / 片假名）、浊音拗音、长音促音、发音规则 | 给出音标能写出对应假名（正确率 90%），看到假名能读出来 |
| 二、N5 基础 | 3–6 | 基础语法（判断句、存在句、动词三类）、约 800 词、日常寒暄 | 能做自我介绍、描述日常作息 |
| 三、N5 巩固 | 7–9 | N5 语法收尾、助词辨析、短文阅读、精读 | 完成 N5 真题，正确率 70% 以上 |
| 四、N4 进阶 | 10–13 | N4 语法与句型、约 1500 词、长句拆解、基础写作 | 能读 300 字短文，写 100 字左右短文 |
| 五、冲刺与复盘 | 14–15 | 真题训练、错题重做、输出练习（默写、造句） | 达到 N4 及格线水平，能完成 3 分钟日常对话 |

> 说明：以上是个人节奏安排，不是官方课程。进度落后时不往后堆，先回头补当阶段的验收项。

## 学习约定

- 每天至少 30 分钟：朗读 5 + 抄写 10 + 做题 10 + 自查 5
- 所有练习都是「看音标写假名」，不搞听写；错题当天进 `mistakes/`
- 周测低于 90% 不学新行，只补错题
- 每月最后一周只复习不学新内容
