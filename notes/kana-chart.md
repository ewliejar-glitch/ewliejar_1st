# 五十音音标对照表（拼音 / 英文锚点）

> 本仓库不做听写。所有练习都是**看音标写假名**：看着右边的音标提示，写出对应假名；反过来看着假名，写出音标。
>
> 拼音和英文只是**近似锚点**，不是日语原音。日语没有中文四声，只有「一拍一拍」的长度和「高 / 低」两种调。朗读时把每个假名读成差不多一样长，不要带中文的升降调。

## 1. 五个元音（最重要，先练到不假思索）

| 假名 | 音标 | 拼音近似 | 英文近似 | 要领 |
| --- | --- | --- | --- | --- |
| あ | a | a（啊） | ah | 嘴自然张开，比中文「啊」小一点 |
| い | i | yi（衣） | ee | 嘴角微拉，短而紧 |
| う | u | wu（乌） | oo（book 里的 oo） | 嘴唇**不圆不突**，几乎是平的 |
| え | e | ê（欸） | e（bed 里的 e） | 下巴略降，别读成中文的「ei」 |
| お | o | o（喔） | o（more 里的 o） | 嘴唇圆，比中文「喔」收得短 |

## 6. 长音、促音、拨音、调

### 长音（拖一拍）

| 规则 | 例子 | 音标 | 读法 |
| --- | --- | --- | --- |
| あ段 + あ | おかあさん | o-ka-a-san | 「か」拖长一拍 |
| い段 + い | おにいさん | o-ni-i-san | 「に」拖长 |
| う段 + う | くうき | ku-u-ki | 「く」拖长 |
| え段 + い | えいが | e-i-ga | 读成「ee-ga」，不是「ei-ga」 |
| お段 + う | がっこう | ga-kko-u | 结尾拖长成 oo |
| 片假名长音 | コーヒー | ko-o-hi-i | 用「ー」表示拖长 |

### 促音（停一拍）

小写「っ」不发音，前面停住一拍再接下一个音。

- がっこう ga-kko-u（「が」后停一拍）
- きって ki-tte（「き」后停一拍）
- いっしょ i-ssho

用拼音想象：两个汉字之间急停一下，如「一·起」，停顿的就是促音。

### 拨音「ん」（占一拍）

- しんぶん shi-n-bu-n
- こんにちは ko-n-ni-chi-wa

### 声调

日语不是四声，是每拍高或低。初学者**先不管调**，先把每拍读等长、读清楚，调子后面再补。

## 7. 「看音标写词」的三种题型

### 题型 A：音标 → 单个假名

| 给定 | 写 |
| --- | --- |
| xi | し |
| qi | ち |
| ci | つ |
| fu | ふ |
| la | ら |

### 题型 B：音标串 → 单词

| 给定 | 写 | 词义 |
| --- | --- | --- |
| ka-sa | かさ | 伞 |
| sa-ka-na | さかな | 鱼 |
| ya-ma | やま | 山 |
| to-ri | とり | 鸟 |
| ne-ko | ねこ | 猫 |
| ma-do | まど | 窗 |

### 题型 C：假名 → 音标（反向自查）

盖住音标列，看假名写出罗马字，这一步比正向更暴露漏洞。

> 用法：每天读表 5 分钟，然后只靠音标写假名，写完再对照。写错的不擦掉，圈出来，第二天重做。
